# WACV 2027 Workshop Website

Website for the **6th Workshop on Image/Video/Audio Quality Assessment in Computer Vision, VLM and Diffusion Model (WVAQ)** at WACV 2027.

Built with plain HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Structure

- `index.html` - Main page
- `styles.css` - Stylesheet
- `script.js` - Mobile nav + smooth scrolling

## Local Development

Open `index.html` in a browser to preview locally.
